# Srinivasan E — Professional Portfolio

A responsive, modern portfolio built with plain HTML, CSS, and JavaScript. It includes your profile photo, education, editable skills and project cards, GitHub/LinkedIn links, contact details, mobile navigation, theme switcher, project filters, scroll progress, and subtle reveal animations.

## Folder contents

- `index.html` — page structure and your portfolio content
- `style.css` — layout, colors, responsive design, animations
- `script.js` — menu, theme, typing effect, filters, copy-email and scroll effects
- `assets/profile.jpg` — the profile photo you supplied

## Step-by-step: run it on your computer

1. Download and extract `srinivasan_portfolio.zip`.
2. Open the extracted `srinivasan_portfolio` folder.
3. Double-click `index.html`. It should open in Chrome, Edge, or Firefox.
4. To edit the portfolio, install Visual Studio Code (VS Code), open the folder using **File → Open Folder**, and edit `index.html`, `style.css`, or `script.js`.
5. Save changes and refresh the browser to see them.

No build tools or package installation are required. An internet connection is only needed for the optional Google Fonts import.

## Personalize it before publishing

1. In `index.html`, edit the About paragraph to describe your real interests and experience.
2. In the Skills section, keep only technologies you have actually studied or used.
3. Replace the three starter project cards with real projects. Update each title, description, technology list, category (`web` or `ai`), and GitHub repository URL.
4. Your supplied portrait is already saved at `assets/profile.jpg`. Replace that file if you want a different photo, keeping the same filename.
5. Check your email, GitHub, and LinkedIn links.

## Publish free with GitHub Pages

1. Sign in to GitHub and open your repository: https://github.com/srinitech46-crypto
2. Create a new public repository named `srinitech46-crypto.github.io` (or use another repository if you prefer a project-site URL).
3. In VS Code, open the extracted portfolio folder. Initialize Git and push the folder to the new repository, or use GitHub's **Add file → Upload files** to upload the contents.
4. For a repository named `srinitech46-crypto.github.io`, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. Your site will normally be available at `https://srinitech46-crypto.github.io/`.

If you use a different repository name, GitHub Pages will usually publish at `https://srinitech46-crypto.github.io/REPOSITORY-NAME/`.

## Important notes

- The contact links use `mailto:`; they open the visitor's email application. This static site does not include a server-side contact form.
- The skill tags and project cards are starter content, not claims that you have completed those projects or mastered those technologies. Replace them with accurate details.
- Do not upload passwords, API keys, private documents, or other sensitive information to a public repository.
